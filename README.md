## Dataset

**Dataset Name:** Drug Consumption UCI (Missing Values)

**Source:** Kaggle

**Dataset Link:** https://www.kaggle.com/datasets/thelonestar033/drug-consumption-uci-missing-values

**Dataset Description:**

* 1,885 records
* 32 original attributes
* Demographic information
* 7 personality-related features
* 19 substance-consumption variables

The dataset was used for data understanding, data cleaning, exploratory data analysis, feature engineering and dimensionality reduction.
